# LENS P3 — view layer on the GPU (2026-11-22)

Branch `feature/aiv20261121_lens_p3` (from `main` `68c704b33`).

## Code changes

- `engine/render/Renderer3D.h/.cpp`, `Renderer3DModels.cpp`: `ModelDraw::layers`
  (appended, default 1 = layer 0) and `Renderer3D::setVisibilityMask/visibilityMask`.
  `beginScene` resets the mask to all layers; `drawModel` skips a draw whose layers do
  not intersect the mask (its shadow in that view too). Meshes, sprites, terrain and
  particles are not filtered.
- `engine/render/CameraRenderPipeline.h`: applies `EcsCameraView::visibilityMask` after
  `beginScene` for every scheduled camera.
- `engine/render/GeometryScene*`: optional instance key `"layers"` (nonzero 32-bit mask);
  validation rejects 0, fractions, > 32 bits and non-default layers with HLOD on (HLOD
  proxies merge instances). Covered in `tests/geometry/runtime.inc`.
- `engine/render/CameraPostFxPool.h`: `setCameraSettings(Entity, PostFxSettings)`,
  `clearCameraSettings`, `hasCameraSettings`: one camera keeps its own PRISMA stack across
  `configure()`; lens exposure/DoF overrides are re-applied after a change.
- `engine/render/CameraPanorama.h`: latitude now follows NDC (zenith at the top row of
  the target); the previous version produced an upside-down equirectangular image.
- `tools/site/lens_showcase.cpp`: layouts `LENS_SPLIT` (+ `LENS_POST2`, `LENS_MASK2`,
  `LENS_LENS2`), `LENS_DIRECTOR`, `LENS_CUBE`, `LENS_MIRROR`, `LENS_PORTAL`,
  `LENS_STEREO` (+ `LENS_XR=1`). Mirror and portal cameras use the camera's oblique
  clip plane.
- PRISMA DoF (same day, already in `main` `6f7e1861c`): foreground bleed and near-field
  edge, see `docs/handoffs/prisma-stage-dof-foreground-bleed-2026-11-21.md`.

## Not done / not verified

- No OpenXR runtime: the loader/headers are Apache-2.0 (needs owner approval) and no
  headset or runtime was available. Swapchain import, frame submission, late latching and
  reprojection remain an XR-host task.
- GL / GLES / WebGL / Vulkan: the panorama orientation and layer filtering are backend
  independent in code but were only rendered on Metal.
- Layer masks do not affect meshes, sprites, terrain or particles.
- The editor does not expose `layers` or per-camera PRISMA settings yet.
