## Stage 1 — race session + FPS host (this entry)

Code:
- `libraries/include/aiverselib/genre/RaceSession.h` (new, header-only, in `AIVERSE::lib_vehicle_controllers`):
  `RaceSessionConfig`, `RaceSessionState`, `makeRaceSession`, `raceSessionInputs` (before the vehicles step:
  countdown / finished brakes, bots via `stepRaceBot`, players' pedals), `stepRaceSession` (after collisions:
  stepRace, phases Countdown -> Running -> Finished, finish grace, timeout), `raceSessionWinner`,
  `raceSessionCountdown`. Persistence: `io(RaceSessionState)`, record kind **128** (new block 128..135 in
  docs/genre-packages.md). Package version 0.2.0.
- FPS host: `fps.mode` `"race"` + `fps.race` (`modules/fps/FpsRace.cpp`, `FpsModule.{h,cpp}`, `FpsVehicles.cpp`):
  players seated as drivers of typed map vehicles on the track grid, locked seats, race bots instead of foot bots,
  `tickVehicles(sim, drive)` override pedals, respawns, winner = team of place 1. `State::race` hashed, saved as
  **FPS save version 10 only when fps.race is set** (other games keep writing v9 byte for byte).
- Network: `Snapshot::race` (`fps::RaceView`), **authority protocol 5 -> 6**. Client prediction no longer moves a
  seated actor on foot (`Client::predict`: `if(predicted_.vehicle) return;`) — generic fix for all typed vehicles.
- Client: `apps/fps/RaceHud.h` (chase camera, HUD), `apps/fps/client.cpp` (oriented, coloured car boxes; map
  colliders with `yaw` drawn as oriented boxes instead of the AABBs of their triangles — generic fix; weapon UI hidden
  in race mode). Lang keys `fps.race.*` (en, ru).
- Sample game `templates/racing` (Oval Sprint) generated by `templates/_tools/racegen.py`.
- Docs: `docs/fps.md` § Races, `docs/genre-packages.md` (race session), `docs/genre-implementation.json` V1/V2/V3 ->
  partial, `docs/ecs-mechanic-composition.md` status row, `docs/genre-mechanics-roadmap.md`, README (+8 translations).
