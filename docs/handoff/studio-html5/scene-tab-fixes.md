# Scene — доработки

Одна ветка на всё, что найдено на вкладке Scene. В неё входят Hierarchy, Project, вид Scene, Game, Inspector и History.

## Делаем

1. Масштаб текста редактора. Ползунок в Editor Settings неудобный: им пользоваться не хочется.
   На Hierarchy шрифт 10–12 пикселей, отдельной настройки размера нет.
   Ползунок UI scale ставит `zoom` на весь документ: страница вылезает за монитор, а трёхмерный вид считается без этого зума и разъезжается с панелями.
   Нужно: текст растёт внутри текущего окна, окно движка остаётся на мониторе, сцена не сдвигается.

2. Пресеты раскладки. Это делаем точно.
   На Scene открыты Hierarchy, Project, Scene, Game, Inspector и History.
   Перетаскивание не даёт собрать свою раскладку, если место уже занято: вкладка падает в существующую стопку, а не в новую колонку. Assets при открытии всегда возвращается вниз (`dock-bottom`), на всю высоту слева её поставить нельзя. Нижняя полоса на всю ширину это не позволяет.
   Сейчас у каждой вкладки редактора (Scene, World, …) помнится одна раскладка в браузере. Именованных пресетов нет.
   Нужно: заводской пресет на каждую основную вкладку и свои сохраняемые пресеты. Для Scene — с вариантом, где Assets на всю высоту слева.

3. Закрытие вкладки колесиком мыши. Сделано.
   Сейчас вкладка закрывается только крестиком. Нажатие на колесико ничего не делает.
   Нужно: щелчок колесиком по вкладке закрывает её, как в браузере.

4. Правый клик по вкладке: разделитель и Add Tab.
   Сейчас меню: Open in New Window, Close, Split Right / Left / Down / Up. Линия перед Split почти не видна.
   В Unity после Close идёт разделитель и Add Tab со списком вкладок, которые встают в эту же стопку.
   Такая команда уже лежит в `stash@{1}` (`EditorTabCommands`): «Закрыть вкладку» и «Добавить вкладку» для project / stats / console. Это старый ImGui-редактор, в HTML её не переносить как есть.
   Нужно: заметный разделитель и пункт Add Tab. Выбранная панель открывается в той стопке, по которой кликнули.

## Окно Windows

5. Верхняя полоса окна.
   На Windows над тёмной шапкой AIVERSE есть белая системная полоса: окно создаётся с `WS_OVERLAPPEDWINDOW`. Свернуть, развернуть и закрыть сидят на ней.
   На Mac этой полосы нет, шапка одна. На Windows при этом ещё включён отступ слева 84 пикселя (`compact-shell--native`): он нужен под кнопки Mac, поэтому слово AIVERSE сдвинуто.
   Нужно: белой полосы нет. AIVERSE вплотную слева. Свернуть, развернуть и закрыть справа, внутри тёмной шапки.

6. Меню Window закрывается от колесика. Сделано.
   Список длинный и должен прокручиваться внутри себя. Сейчас любой `wheel` закрывает меню (`StudioContextMenu`), поэтому до нижних пунктов не добраться.
   Нужно: колесико над меню листает список. Закрытие остаётся по клику снаружи и по Escape.

7. Наполнение меню Window.
   Сейчас сначала все панели в порядке списка, потом Workspaces, потом команды.
   Нужно сверху вниз: Workspaces, разделитель, системные команды (Reset Layout, Command Palette, Welcome Tour), открытые на этой вкладке окна с галочками, затем остальные окна фич по алфавиту.
   На Windows у Workspaces и команд рисуется знак ⌘. Там должен быть Ctrl.

8. Системная иконка окна.
   В белой полосе слева стоит стандартный значок Windows. Окно просит ресурс 1, а в `AiverseStudio.rc` под этим номером только манифест, не иконка.
   Нужно: в заголовке и на панели задач знак AIVERSE (`engine/assets/branding/mark.png`). Когда белой полосы не станет, тот же знак остаётся слева в тёмной шапке и на панели задач.
