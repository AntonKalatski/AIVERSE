# LENS: поведение камер и пресеты

Каждая видовая камера AIVERSE строится из одного набора тел камеры в `engine/render/CameraBehavior.h`, а ECS-риг
(`CameraRigComponent`, `engine/render/CameraRig.h`) использует ту же математику. Проект выбирает тело блоком камеры,
который пишет, и начинает с именованного пресета; отдельных классов камер под игры нет.

| Тело | Блок | Что делает |
|---|---|---|
| обзор карты | game.json `"camera"` | Свободная камера карты: проекция, наклон, поворот, объектив, пределы зума, пиксель-в-пиксель в орто |
| следование | game.json `topDown.camera`, `"camera"` карты | Держит точку в кадре: сглаживание, упреждение по движению и прицелу, отъезд от скорости, упреждение по скорости, границы карты, объектив и плоскости отсечения |
| преследование | rules / карта `"camera": {"chase": {...}}` | Сзади и выше направления (техника): расстояние, высота, наклон, вынос цели, объектив |
| от первого лица | rules / карта `"camera": {"firstPerson": {...}}` | Глаза и обзор мышью: чувствительность (и при прицеливании), предел наклона, объектив |

## Пресеты

`engine/render/CameraPresets.h` хранит именованные пресеты в JSON. Блок называет пресет и переопределяет любые ключи:

```json
"camera": {"preset": "overhead-pixel"}
"topDown": {"camera": {"preset": "follow-speed", "distance": 20}}
"camera": {"chase": {"preset": "chase-low"}, "firstPerson": {"preset": "first-person", "sensitivity": 0.0005}}
```

| Пресет | Тело | Кадр |
|---|---|---|
| `overhead` | обзор карты | Перспектива, наклон 54°, поворот разрешён |
| `overhead-flat` | обзор карты | Круче, без поворота |
| `overhead-pixel` | обзор карты | Ортографически сверху, 32 пикселя на клетку (спрайтовые игры) |
| `overhead-isometric` | обзор карты | Ортографически 35,264° / 45° (изометрия) |
| `follow` | следование | Следование сверху с упреждением по стику и прицелу |
| `follow-overhead` | следование | Строго сверху, короткое упреждение |
| `follow-speed` | следование | Строго сверху, отъезжает и уходит вперёд со скоростью |
| `follow-telephoto` | следование | Узкий объектив 20° издалека, туман по объективу |
| `chase` | преследование | Камера техники по умолчанию (11 м сзади, 1,4 м вверх) |
| `chase-low` | преследование | Ближе и ниже, шире угол |
| `first-person` | от первого лица | Обзор от первого лица по умолчанию |

Неизвестное имя пресета `resolveCameraPreset` сообщает как ошибку, ключи самого блока остаются. Новый пресет —
изменение данных в `CameraPresets.h`; ключи — те же, что у блока тела.

## Режимы ECS-рига

`CameraRigComponent::mode`: `Static`, `LookAt`, `Follow`, `Orbit`, `Rail`, `Chase`, `FirstPerson`.
`Chase` берёт `distance`, `pitch`, `offset.y` (высота), `offset.z` (вынос цели вперёд) и `yaw` (поворот вокруг
направления); `FirstPerson` ставит глаз в цель плюс `offset` (поворачивается вместе с целью) и смотрит вдоль её +Z,
добавляя `yaw` / `pitch`. Тряска (`CameraShakeComponent`) и физический объектив (`CameraLensComponent`) работают
поверх любого режима. Тест: `camera_behavior` (пресеты, все тела, ECS Chase / FirstPerson против видовой камеры
преследования).
