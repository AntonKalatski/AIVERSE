# Добавление окна в редактор

Редактор (`apps/editor`) — это набор стыкуемых окон Dear ImGui (ветка docking). Каждое окно —
небольшой класс; редактор создаёт по одному экземпляру каждого зарегистрированного класса, показывает его в верхнем
меню его группы (`group()`, см. ниже), пристыковывает его в раскладку по умолчанию, сохраняет раскладку пользователя
(`<userDataDir>/editor_layout.ini`) и позволяет агентам открывать/закрывать его через MCP (`editor_windows`,
`editor_window`).

## 1. Создайте файл

Положите файл `.cpp` в `apps/editor/windows/`. Каждый файл там автоматически компилируется в редактор
(CMake `GLOB ... CONFIGURE_DEPENDS`), больше ничего регистрировать не нужно.

```cpp
// apps/editor/windows/BalanceWindow.cpp
#include "../Editor.h"
#include "../EditorUtil.h"     // ui::inputString, ui::inputMultiline, ui::help

namespace aiverse::editor {

class BalanceWindow : public EditorWindow {
public:
    const char* id() const override { return "balance"; }        // stable latin id (MCP, layout)
    const char* title() const override { return "Баланс"; }      // tab title, Russian (must be unique)
    const char* group() const override { return "logic"; }       // top menu: scene | world | look | logic | publish | service
    const char* dockArea() const override { return "bottom"; }   // left | left-bottom | right (Inspector) | right-bottom (rules, world / look tools) | center | bottom
    int order() const override { return 5; }                     // tab order in that area (0 = shown first)
    bool openByDefault() const override { return false; }        // hidden until opened from the menu

    void draw(Editor& ed) override {                             // called between ImGui::Begin/End
        for (auto& t : ed.rules().types) {
            if (t.cost.empty()) continue;
            ImGui::Text("%s: %lld hp", t.name.c_str(), (long long)t.maxHp.toInt());
        }
    }
    void update(Editor& ed, double dt) override {}              // optional: every frame, even when closed
};

AIVERSE_EDITOR_WINDOW(BalanceWindow);

} // namespace aiverse::editor
```

`title()` — это простой текст вкладки (его сообщает MCP `editor_windows`). Имя ImGui —
`imguiName()` = `"<icon>  <title>###<id>"`: часть `###id` делает стабильными стыковку, сохранённые раскладки и фокус.
Используйте `imguiName()` (или `ed.focusWindow("id")`) всегда, когда ImGui нужно имя окна. Значок вкладки
берётся из `windowIconFor(id())` в `EditorIcons.h`, или переопределите `icon()`.

Пересоберите редактор; окно появится в меню своей группы. Новые окна присоединяются к вкладкам своей
`dockArea` при первом открытии; **Вид → Сбросить раскладку** заново строит раскладку по умолчанию.

### Меню и группы

| `group()` | Верхнее меню | Окна | Рабочее пространство (Вид → Раскладки) |
|---|---|---|---|
| `scene` | **Сцена** | Сцена, Игра, Иерархия, Инспектор, Инструменты | Карта и объекты |
| `world` | **Мир** | Рельеф, Тайлы, Генерация, Материалы, Поля, Туман войны | Ландшафт |
| `look` | **Графика** | Освещение, Постэффекты, Эффекты, Модели, Оверлеи | Графика и эффекты |
| `logic` | **Логика** | Проект, Правила, Скрипты, Статистика (+ запуск теста) | Правила и тест |
| `publish` | **Сборка** | Сборка, Иконки и заставка (+ цели сборки) | Выпуск |
| `service` | **Вид** | Консоль, ИИ-агент | — |
| что-либо другое | **Вид → Другие окна** | | |

Рабочее пространство (`Editor::openWorkspace(group)`) открывает окна по умолчанию и все окна группы,
перестраивает раскладку и выводит вкладки группы на передний план. Щелчок по окну в меню открывает его и
выводит на передний план; повторный щелчок, когда оно уже впереди, скрывает его.

Другие меню: **Файл** (проекты, карты), **Правка** (отмена, симметрия, пандусы, проверка карты), **Вид** (служебные
окна, рабочие пространства, что показывает Сцена, тема). Горячие клавиши: Ctrl/Cmd+S сохранить, Ctrl/Cmd+Z / Y отмена/повтор,
F5 тест, Ctrl/Cmd+B окно сборки; в Сцене 1…0 выбирают инструменты, F фокус, [ ] размер кисти, Delete удаляет.

## 2. Что может использовать окно (публичный API `Editor`, `apps/editor/Editor.h`)

| API | Для чего |
|---|---|
| `ed.ws()` | `Workspace`: проект (манифест, `rulesJson`, разобранные `rules`), документ карты, журнал действий и **`ws().call(op, params)`** — запуск любой MCP-операции (`rules_set`, `entity_place`, `match_run`, ...) точно так же, как это делает агент; предпочитайте это прямому редактированию данных, так данные проверяются и записываются в историю |
| `ed.doc()` | открытая карта (`MapDoc`): `data` (слои рельефа, игроки, сущности, дороги, JSON-блоки `extra`), `beginEdit()` перед изменением (снимок для отмены), `touched()` после изменения (виды перестраиваются) |
| `ed.rules()` | разобранные правила открытой игры (только чтение; правила меняйте через `rules_set`) |
| `ed.selection`, `ed.select(...)`, `ed.selectEntity(i)` | что показывает Инспектор (основной элемент) |
| `ed.selected()`, `ed.selectToggle/selectAdd/selectMany`, `ed.isSelected(s)`, `ed.selectedEntities()`, `ed.removeSelectedEntities()` | множественный выбор (Иерархия, Сцена, Инспектор «Детали»); `Selection::Live` = объект мира по `ref` |
| `ed.world()`, `ed.worldLive()`, `ed.worldSim()`, `ed.worldRow(s)`, `ed.worldSelection(row)`, `ed.refreshWorld()` | дерево мира: каждый объект игрового мира — в режиме редактирования: setup карты, запущенный во временном предпросмотре; в игре: запущенный тест (docs/editor-world-tree.md) |
| `ed.hover`, `ed.setHover(s)`, `ed.pickObject(vp, cam, x, y)`, `ed.sceneHidden` / `ed.sceneLocked` | наведение, общее для Сцены и Иерархии, выбор любого объекта, глаз / замок в Сцене |
| `ed.tool`, `ed.brush`, `ed.placeType`, ... | состояние инструментов Сцены |
| `ed.sceneCam`, `ed.focusScene(x, z)`, `ed.flash(x0, z0, x1, z1)` | камера и подсветка в Сцене |
| `ed.playing()`, `ed.sim()`, `ed.simModule()`, `ed.startPlay(slot)`, `ed.stopPlay()` | симуляция тестовой игры (из окон только чтение; команды игрока отдавайте через `ed.issueCommand`) |
| `ed.playHistory`, `ed.frameHistory` | собранная статистика |
| `Viewport` + `ed.renderScene(vp, cam, overlays)` / `ed.renderGame(vp, cam)` | 3D-вид карты внутри вашего окна (см. `SceneWindow.cpp`: `vp.ensure()`, отрисовка, `vp.image()`) |
| `ed.status` | текст в строке состояния |

Правила для окон:
- Никогда не пишите в симуляцию (`ed.sim()`): она детерминирована и воспроизводима; используйте команды.
- Меняйте правила и карты через `ws().call(...)` или `doc().beginEdit()` + правка + `doc().touched()`.
- Храните состояние окна в полях класса (по одному экземпляру на окно).
- Текст интерфейса на русском, код и комментарии на английском (см. AGENTS.md).

## 3. Внешний вид: тема, значки, панели инструментов

Стиль редактора (тёмная / светлая тема, предустановки акцента, меню **Вид → Тема**, MCP `editor_theme`) находится в
`apps/editor/EditorTheme.*`; окна не задают собственных цветов. Предпочитайте цвета темы
(`ImGui::GetStyle().Colors`, `ui::accentColor()`, `ed.theme().palette()`) жёстко заданным RGB, чтобы
обе темы оставались читаемыми.

Значки: шрифт Lucide, объединённый со шрифтом интерфейса, константы в `apps/editor/EditorIcons.h`
(`ImGui::Button(ICON_PLAY " Играть")`). Помощники в `EditorUtil.h`:

| Помощник | Что |
|---|---|
| `ui::toolButton(ICON_X, "Подсказка", active, enabled)` | квадратная кнопка-значок: состояния наведения / активности (акцент), всплывающая подсказка |
| `ui::beginSegment()` / `ui::endSegment()` | сегментированная группа кнопок инструментов на одном фоне (`SameLine()` между ними) |
| `ui::toolbarDivider()` | тонкий вертикальный разделитель между группами |
| `ui::beginToolbar()` / `ui::endToolbar(y)` | полоса панели инструментов вверху окна с `zeroPadding()` (Сцена, Игра) |
| `ui::button(ICON_X, "Текст", primary)` | кнопка со значком и подписью; `primary` = залита цветом акцента |
| `ui::emptyState(...)` / `ui::emptyStateHere(icon, title, hint)` | заглушка по центру: крупный значок, заголовок, подсказка |
| `ui::heading("Текст")` | заголовок раздела полужирным шрифтом заголовков |
| `ui::checkbox("Текст", &v)` | флажок, подпись которого сокращается с «…» до ширины колонки (полный текст во всплывающей подсказке); используйте вместо `ImGui::Checkbox` |
| `ui::button` / `ui::wideButton` с шириной | не помещающаяся подпись сокращается с «…», полная подпись во всплывающей подсказке |
| `ui::collapsing("Секция")` | сворачиваемый раздел в нейтральном цвете рамки (стандартный вид ImGui выглядит выбранным) |
| `ui::inputHint("##id", "подсказка", str)` | текстовое поле `std::string` с заполнителем |
| `ui::pathText(path, maxW)` / `ui::prettyPath(path)` | путь для показа: домашний каталог как `~`, сокращение слева, полный путь при наведении |
| `ed.sceneVisible()` | вкладка Сцены отрисовалась в этом кадре: проверяйте это перед отрисовкой гизмо или рисованием через `ed.sceneViewport` (скрытая вкладка оставляет устаревший viewport) |
| `ui::section(ICON_X, "Текст")` | заголовок раздела со значком и тонкой линией до правого края (вместо `SeparatorText`) |
| `ui::beginProps("##id")` + `ui::prop("Подпись", "подсказка")` + виджет с подписью `"##"` + `ui::endProps()` | сетка свойств: приглушённые подписи в левой колонке, виджеты во всю ширину справа; `ui::propWide()` для отдельной строки (флажок, кнопки) |
| `ui::searchField("##id", str, "Подсказка")` | поле поиска с подсказкой внутри и кнопкой очистки; `ui::contains(text, filter)` сравнивает без учёта регистра |
| `ui::segmented("##id", value, labels, n)` / `ui::choiceGrid(...)` | переключатель режима во всю ширину / переносимые плитки для 5+ вариантов |
| `ui::callout(ui::Tone::Warn, "…")`, `ui::resultMessage(msg)` | тонированная плашка со значком для результатов, предупреждений, ошибок (`resultMessage` угадывает тон) |
| `ui::toneText(tone, fmt, ...)`, `ui::toneColor(tone)`, `ui::badge(text, color)` | цвета темы для текста ok / предупреждения / ошибки и маленьких значков-счётчиков — никогда не жёстко заданные RGB |
| `ui::headerCard(icon, title, subtitle, color)` | карточка вверху панели (Инспектор: что выбрано) |
| `ui::wideButton(icon, text, index, count, primary)` | кнопки, поровну делящие одну строку |
| `ui::hint("…")`, `ui::menuItem(icon, text, shortcut)`, `ui::viewportLabel(dl, pos, text)` | приглушённая строка пояснения, пункт меню со значком, читаемая подпись поверх 3D-вида |

Правила стиля: текст интерфейса на русском; окно, которому нечего показать, рисует `ui::emptyStateHere` с тем, что сделать;
результаты действий выводятся в плашку в окне (и в `ed.status` для строки состояния); другие
окна называйте по их русскому заголовку в «ёлочках» («Сцена», «Консоль»).

## 4. Доступ для агентов

Если окно добавляет действие, которое должен уметь выполнять агент, зарегистрируйте операцию (в
конструкторе окна это слишком рано; сделайте это один раз в `update()` или в `EditorAgent.cpp`):

```cpp
ed.ws().registerOp({"balance_report", "Damage per cost of every unit type.", Json::parse("{}"),
                    [&ed](const Json&) { Json r = Json::object(); /* ... */ return r; }, true});
```

Операции появляются в MCP `tools/list` для агентов, подключённых через `aiversemcp` (список инструментов — это
реестр `Workspace`; операции только для GUI имеют `guiOnly = true` и вежливо завершаются ошибкой без
окна редактора).

## Игровой HUD

Тестовая игра в окне Игра отрисовывает `ui/hud.rml` и `ui/howto.rml` через RmlUi в своём
viewport после сцены. Недостающие документы, стили и изображения берутся из
`engine/assets/ui`; игровые шрифты (`fonts/ui.ttf`, `fonts/title.ttf`) берутся так же, как в клиенте.
Редактор выбирает язык игры по тем же правилам сохранённого выбора / языка системы.
Перезапустите тестовую игру после правки RML, RCSS или шрифтов, чтобы перезагрузить их.

`apps/client/UiModel.h` владеет общей схемой модели `game` и обновлениями только при изменениях.
`apps/editor/GameHud` адаптирует симуляцию редактора к этой модели: панели ресурсов/состояния,
карточки HUD из скриптов, вспомогательные действия и соотношения регионов. Кнопки отдают Commands;
пауза/перезапуск/остановка действуют на тестовую игру редактора. Координаты указателя локальны для
viewport; раскладка и проекция RmlUi используют размер его кадрового буфера и плотность устройства.
Маркеры регионов в мировом пространстве остаются оверлеями редактора.

Это встроенный HUD тестовой игры, а не второй GameClient: поток лобби/меню клиента,
API `game` в UI Lua, воспроизведение звука и полная стандартная карточка команд/миникарта RTS клиента
адаптером редактора не размещаются. Для них используйте **Игру как в клиенте** ниже.

## Игра как в клиенте

Окно Игра также может запустить игру ровно так, как это делает AiverseGame: тот же `GameClient`
(`apps/client/GameClient*.cpp`, `Client*.cpp`; `main.cpp` из AiverseGame добавляет только точку входа),
размещённый в `apps/editor/ClientHost` и отрисованный во внеэкранную цель окна, внутри рамки
симулятора устройства. Всё принадлежит клиенту: меню / мета-экраны игры
(`ui/main.lua`, `ui.screen` / `ui.popup`), параметры запуска, поток бой -> результат -> мета,
скрипты вида (отрисовка, камера, HUD-документы, `view.ui_call`), UI из скриптов, ввод (правила `mapClick`
— тап при отпускании, перетаскивание левой кнопкой для сдвига, колесо для масштаба, HUD-элементы `map-drag`, щелчки RmlUi, клавиши),
экран паузы и звук. Собственные инструменты тестовой игры редактора (боты против ботов, выбор игрока, скорость,
пауза, статистика) остаются для тестирования карты; оба режима никогда не работают одновременно.

- Запуск: кнопка геймпада на панели инструментов Игры, «Как в клиенте» под пустым окном Игры,
  всплывающее меню игры в верхней панели, меню Логика → Тест, MCP `play_start {"client": true}`; F5 и
  кнопка Играть в верхней панели запускают его для игр со своими экранами (`ui/main.lua`). Остановка /
  перезапуск на панели инструментов Игры, F5, `play_stop`; собственный Выход игры тоже останавливает его.
- «В отдельном окне клиента» (кнопка внешней ссылки): проект в отдельном окне AiverseGame
  (AIVERSE_CONTENT = проект), в первую очередь тот, что собран рядом с этим редактором (те же модули C++).
- Модули C++ проекта (правила `nativeModules`) должны быть в бинарнике редактора, как и для
  тестовой игры (баннер предлагает сборку редактора для проекта).
- Размещение: пока хост вызывает клиент, он устанавливает `platform::setHostedView` (логический размер
  экрана устройства, размер кадрового буфера, масштаб, безопасная область предустановки устройства, касания, корень контента =
  проект, `engine/...` -> ассеты движка; `requestQuit` / полноэкранный режим записываются, заголовок
  окна не меняется) и затем восстанавливает контекст ImGui редактора (каждый `ImGuiLayer` владеет
  своим контекстом). События указателя внутри экрана устройства (или захваченные нажатием внутри) и клавиши,
  пока окно Игра в фокусе, переводятся в точки экрана и передаются дальше.
- Профили / сохранения попадают в каталог пользовательских данных редактора (`AIVERSE_UI_SAVE_DIR` переопределяет, как в клиенте).
- Командная строка (автоматические проверки): `aiverse_editor --project <dir> --play-client --device iphone-se:portrait --window game`.
